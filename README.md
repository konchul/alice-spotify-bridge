# 🎵 Alice Spotify & AirPlay Lossless Bridge

Беспроводной стриминг **Spotify Connect** и **Apple AirPlay** на любую **Яндекс Станцию** (с Алисой) по локальной сети в оригинальном качестве **Lossless WAV 1411.2 kbps (bit-perfect)**.

Проект превращает Яндекс Станцию в полноценный Hi-Fi аудиоресивер с **двусторонней синхронизацией громкости**, отображением обложек/названий треков и мгновенным откликом. Поддерживает работу на **Ubuntu / Debian / Raspberry Pi** и на роутерах с **OpenWrt** (через легковесный chroot).

---

## 💎 Почему звук такой качественный? (Глубокий разбор)

Большинство существующих способов передать музыку со смартфона на Яндекс Станцию имеют серьезные компромиссы по качеству:
1. **Bluetooth**: использует кодеки SBC или AAC с сильным сжатием. Исходный трек сначала распаковывается телефоном, затем с потерями сжимается в Bluetooth-кодек, передается по радиоканалу и снова декодируется колонкой. Результат — задержка 1.5–2 секунды, срезанные верхние частоты (выше 16 кГц), глухой бас и периодические заикания.
2. **Старые DLNA/MP3 мосты**: перекодируют звук «на лету» с помощью FFmpeg/LAME в MP3 (192–320 kbps). Это повторное сжатие с потерями (lossy re-encoding), которое нагружает процессор роутера и вносит фазовые искажения.

### Как устроен звук в этом проекте: **Bit-Perfect Lossless 1411.2 kbps**

В этом проекте перекодирование звука **полностью отсутствует (Zero-Transcoding)**. 

```
[ Spotify CDN / Apple Device ]
             │
             ▼ (исходный аудиопоток)
[ Soloist (Spotify eSDK) / Shairport-Sync (AirPlay) ]
             │
             ▼ Декодирование в несжатый Linear PCM (44.1 кГц, 16-бит стерео)
[ PulseAudio / PipeWire (auto_null sink) ]
             │
             ▼ Прямой захват байт в байт (parec, 50ms чанки)
[ bridge.py (WAV Stream Server :8888) ]
             │
             ▼ Бесконечный PCM WAV-поток без сжатия (HTTP)
[ Аппаратный декодер Яндекс Станции (GStreamer) ]
             │
             ▼
[ ЦАП и акустика Станции ]
```

* **Математика качества**:
  $$\text{Битрейт} = 44\,100 \text{ Гц} \times 16 \text{ бит} \times 2 \text{ канала} = 1\,411\,200 \text{ бит/с} = \mathbf{1411.2 \text{ кбит/с}}$$
* **Поток 1:1**: Несжатый PCM-звук оборачивается в стандартный контейнер WAV (RIFF WAVE) и по локальной Wi-Fi сети отдаётся плееру Яндекс Станции.
* **Частотный диапазон**: Полный слышимый спектр от **20 Гц до 20 000 Гц** без срезов компрессоров.
* **Динамический диапазон**: **96 дБ** (честное качество Audio CD).
* **Минимальная нагрузка**: Так как роутеру не нужно сжимать аудио в MP3, нагрузка на процессор составляет менее **1-2%**, а потребление оперативной памяти аудио-стеком — всего около **150 МБ** (из которых PulseAudio занимает рекордные ~8 МБ).

## 📊 Сравнение методов передачи звука

| Параметр | Bluetooth на Станцию | Старый MP3-мост | **Этот проект (Lossless WAV)** |
| :--- | :--- | :--- | :--- |
| **Формат аудио** | SBC / AAC (сжатие) | MP3 192-320 kbps (сжатие) | **PCM WAV (Lossless, без сжатия)** |
| **Реальный битрейт** | ~250–320 kbps | 192–320 kbps | **1411.2 kbps (Bit-Perfect CD Quality)** |
| **Повторное сжатие** | Да (двойное) | Да (mp3lame) | **Нет (0% потерь качества)** |
| **Частотный срез** | Срезано выше 16-17 кГц | Срезано выше 18 кГц | **Полные 20 Гц – 20 000 Гц** |
| **Задержка старта** | 1.5 – 3.0 сек | 2.0 – 4.0 сек | **< 0.35 сек (Pre-roll буфер 500 мс)** |
| **Громкость с кнопок Станции** | ❌ Не синхронизирует Spotify | ❌ В одну сторону | **✅ Двусторонняя (кнопки Станции ⇄ Spotify)** |
| **Отображение метаданных** | Частично | Текст | **✅ Название, Артист и Обложка трека** |
| **Нагрузка на CPU** | Средняя | Высокая (кодирование MP3) | **Минимальная (< 2% CPU)** |

> [!IMPORTANT]
> **Требование к подписке Spotify**: Для работы **Spotify Connect** на любых встраиваемых аудиоустройствах компания Spotify на уровне протокола требует наличие активной подписки **Spotify Premium** (бесплатные аккаунты Spotify Connect на внешнем железе не поддерживаются).
> Для стриминга через **Apple AirPlay** никакие подписки не требуются — передается абсолютно любой звук с iPhone, iPad или Mac.

## 🛠️ Что нужно для работы

1. **Сервер или роутер в локальной сети**:
   * Любой ПК / сервер / Raspberry Pi / мини-ПК под управлением **Ubuntu 20.04/22.04/24.04**, **Debian** или **Raspberry Pi OS**.
   * *Либо:* Роутер с **OpenWrt** (x86_64 или aarch64) с USB-портом и подключенной флешкой (под легковесный Ubuntu chroot).
2. **Яндекс Станция**:
   * Любая модель (Станция 1, Станция 2, Станция Макс, Миди, Мини 1/2, Лайт 1/2, ТВ Станции).
   * Колонка должна быть подключена к той же локальной сети (Wi-Fi), что и сервер/роутер.
3. **Учетная запись Spotify Premium**:
   * Для работы Spotify Connect на сторонних/встраиваемых устройствах (Spotify eSDK / Soloist) **обязательно требуется активная подписка Spotify Premium** (это официальное требование протокола Spotify).
   * Управление воспроизведением осуществляется из официального приложения Spotify (iOS, Android, macOS, Windows, Linux).
4. **Устройство Apple (опционально, подписка не требуется)**:
   * iPhone, iPad или Mac для беспроводного воспроизведения любого звука через AirPlay.

## 🔑 Где и как получать ключи и токены

Для работы моста требуются всего два параметра авторизации: **Spotify Developer API Key** и **Yandex Session_id**.

### 1. Яндекс `Session_id` (Cookie авторизации)

Яндекс Станция управляется по локальному протоколу **Glagol (порт 1961)**. Для подключения к колонке требуется кратковременный токен, который бридж запрашивает у облака Яндекса каждые 25 секунд. Для этого запроса и нужен `Session_id`.

**Как получить за 1 минуту:**
1. Откройте браузер на компьютере (Chrome, Яндекс Браузер, Firefox или Edge).
2. Перейдите на [yandex.ru](https://yandex.ru) или [quasar.yandex.ru](https://quasar.yandex.ru) и авторизуйтесь под тем аккаунтом, к которому привязана Станция.
3. Нажмите клавишу **F12** (или `Ctrl + Shift + I`), чтобы открыть панель разработчика (DevTools).
4. Перейдите во вкладку:
   * В Chrome / Яндексе: **Application** (Приложение) → слева раскройте **Cookies** → выберите `https://yandex.ru`.
   * В Firefox: вкладка **Storage** (Хранилище) → **Cookies** → `https://yandex.ru`.
5. В списке найдите строку с именем **`Session_id`**.
6. Скопируйте её значение (длинная строка, начинающаяся с `3:...`).
7. Вставьте это значение в мастере настройки `setup.py` или в `config.json`.

> [!NOTE]
> Cookie `Session_id` живёт очень долго (обычно от нескольких месяцев до года), пока вы явно не нажмёте кнопку «Выйти» из аккаунта в этом браузере.

---

### 2. Spotify Developer API Key (`spak_...`)

Бинарник **Soloist** (официальный встраиваемый Spotify eSDK) использует специальный ключ разработчика для объявления устройства в протоколе Spotify Connect.

* Ключ имеет формат: `spak_XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX`.
* Вы можете получить собственный ключ в [Spotify Developer Dashboard](https://developer.spotify.com/dashboard), создав приложение eSDK, либо использовать готовый ключ Soloist, который интерактивный мастер `setup.py` подставит автоматически.

---

### 3. Локальный IP-адрес Станции и обязательная фиксация (Static Lease)

Связь с колонкой происходит напрямую по локальной сети через порт `1961` без обращения к серверам Яндекса в момент стриминга.

> [!WARNING]
> **КРИТИЧЕСКИ ВАЖНО ЗАФИКСИРОВАТЬ IP КОЛОНКИ В РОУТЕРЕ!**
> По умолчанию роутер может переназначить IP-адрес Станции при перезагрузке или переподключении Wi-Fi. Если адрес изменится, бридж не сможет подключиться к колонке.

**Как закрепить IP-адрес:**
1. Зайдите в панель управления вашего роутера (например, `192.168.1.1`).
2. Найдите раздел **DHCP** / **Статические адреса** (**Static Leases** / **Привязка IP к MAC**).
3. Найдите в списке клиентов вашу Яндекс Станцию (её MAC-адрес также можно посмотреть в приложении «Дом с Алисой» в свойствах колонки).
4. Нажмите «Зафиксировать» или «Добавить в статические» и закрепите за ней постоянный IP (например, `192.168.1.102`).
5. Сохраните настройки роутера.

---

### 4. Device ID и Platform (Автопоиск через `setup.py`)

Вам **не нужно вручную искать** идентификаторы колонки (`device_id`) и кодовые имена платформ (`platform`). 

В проект встроен интерактивный мастер:
```bash
python3 setup.py
```
После ввода `Session_id` мастер сам соединится с сервером Яндекса, выведет список всех ваших Станций и предложит выбрать нужную:
```text
✅ Найдено устройств с Алисой: 2
Выберите вашу Яндекс Станцию:
  [1] Гостиная (Станция 2)  |  Модель: yandexstation_2  |  ID: M00M5SQ...
  [2] Кухня (Мини 2)        |  Модель: yandexmini_2     |  ID: MG00000...

Введите номер устройства [1-2]: 1
-> Выбрано: Гостиная (Станция 2)
```

Также узнать список ваших колонок в любой момент можно командой:
```bash
python3 bridge.py --list-devices
```

## 🚀 Быстрый старт

### Вариант 1: Установка на Ubuntu / Debian / Raspberry Pi

1. **Установите системные пакеты**:
   ```bash
   sudo apt update
   sudo apt install -y python3 python3-pip pulseaudio pulseaudio-utils shairport-sync
   ```

2. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/konchul/alice-spotify-bridge.git
   cd alice-spotify-bridge
   pip3 install -r requirements.txt
   ```

3. **Установите бинарник Soloist (Spotify Connect)**:
   Поместите бинарник `soloist` в `/usr/local/bin/soloist` и сделайте его исполняемым:
   ```bash
   sudo chmod +x /usr/local/bin/soloist
   ```

4. **Запустите мастер настройки**:
   ```bash
   python3 setup.py
   ```
   Следуйте подсказкам мастера — он сгенерирует безопасный `config.json` и проверит соединение с колонкой по порту 1961.

5. **Включите автозапуск через systemd**:
   ```bash
   sudo cp systemd/*.service /etc/systemd/system/
   sudo systemctl daemon-reload
   sudo systemctl enable --now soloist.service alice-spotify-bridge.service
   ```

---

### Вариант 2: Установка на OpenWrt (роутер)

На роутерах под управлением OpenWrt (musl libc) бинарник `soloist` (скомпилированный под glibc) работает внутри компактного Ubuntu rootfs (chroot) в оперативной памяти (tmpfs).

1. Скопируйте файлы репозитория на флешку роутера (`/mnt/usb/`).
2. Скопируйте и запустите службу procd:
   ```bash
   cp openwrt/spotify_bridge.init /etc/init.d/spotify_bridge
   chmod +x /etc/init.d/spotify_bridge
   /etc/init.d/spotify_bridge enable
   /etc/init.d/spotify_bridge start
   ```
3. Запустите мастер настройки:
   ```bash
   /root/setup.sh
   ```

## 🎛️ Интеллектуальные функции под капотом

* **Токенизация потока (`?t=N`)**: плеер Яндекс Станции агрессивно кэширует поток. Чтобы при переключении трека или снятии с паузы не играл старый кусок из буфера, бридж инкрементирует токен стрима, моментально сбрасывая воспроизведение старого аудио.
* **Изоляция клиентов по IP**: бридж отслеживает активные сетевые сокеты Алисы. Если колонка переподключается, предыдущее «подвисшее» TCP-соединение немедленно вытесняется, исключая заторы в буфере.
* **Двусторонняя регулировка громкости**:
  * Крутите громкость на самой Станции — ползунок в Spotify плавно смещается.
  * Регулируете звук в Spotify на телефоне — Станция плавно меняет громкость с шагом 10%.
  * Встроен 3-секундный кулдаун против эффекта обратной связи (loopback).
* **Автоприоритет AirPlay и Spotify**:
  * Играет Spotify, и вы включили AirPlay на iPhone? Spotify автоматически встанет на паузу, и заиграет звук с iPhone.
  * Включили трек в Spotify? AirPlay мягко завершит сессию и уступит воспроизведение Spotify.
